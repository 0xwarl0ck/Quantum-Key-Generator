# Quantum Key Generator

An optimized Go utility that generates cryptographically strong strings by tapping into real-time quantum vacuum fluctuations via the **ANU Quantum Numbers API**. 
Unlike standard pseudo-random generators, this tool uses quantum entropy to ensure true randomness.



## Usage
The -key flag will let you specify your API key.
The -len flag will let you specify the password length.
The -out flag will let you create an output file.
